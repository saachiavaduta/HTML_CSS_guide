# HTML & CSS Concept Explanations

These files explain the concepts behind every question (Q1–Q120). Read them when you want to understand *why* an answer is correct, not just memorise it. Each topic file starts from the basics, then shows how the exam questions use the idea.

The matching answer keys are in `exam-answers/`.

## How to study

1. Read the topic file for a concept.
2. Open the note folder listed for that topic in the repository (`Semester-1/HTML_CSS_JS/`) and compare.
3. Open the answers for the questions listed, and try to write the code yourself before reading the solution.

## Checking status

Every note folder cited in these files was read from the repository and compared with the explanations. The question lists in the table are topic-level: they name the questions that use or illustrate each concept, and they were checked against the answer keys. The original exam paper was not available, so question wording was compared only through the answer-key headings.
