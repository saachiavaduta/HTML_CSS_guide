# CSS Text

Source: CSS/11.CSS_Text

## Key points
- Text properties style the text inside an element; they do not change the element's box or layout.
- `color` sets text colour (name, hex, rgb, hsl).
- `text-align`: `left`, `right`, `center`, `justify`.
- `text-decoration`: `none`, `underline`, `overline`, `line-through`. Shorthand: `style color thickness`.
- `text-transform`: `uppercase`, `lowercase`, `capitalize`.
- `letter-spacing` and `word-spacing` adjust gaps between characters and words (negative values tighten).
- `text-shadow`: `h-offset v-offset blur colour`; multiple shadows separated by commas.
- Most text properties are inherited by child elements.

## Syntax / example
```css
h2 {
  color: coral;
  text-align: center;
  text-decoration: underline blue 2px;
  text-transform: uppercase;
  letter-spacing: 3px;
  word-spacing: 5px;
  text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.5);
}
```

## Remember
- Text properties style content; `border` and `outline` affect the box.
- `text-decoration` shorthand order: style, colour, thickness.
- `text-transform` changes display only, not the stored text.
- Text properties are inherited unless overridden.
