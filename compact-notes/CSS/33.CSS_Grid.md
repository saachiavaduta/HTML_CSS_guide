# CSS Grid

Source: CSS/33.CSS_Grid

## Key points
- CSS Grid is a two-dimensional layout system. It controls rows and columns at the same time.
- Set `display: grid` on the container. Its children become grid items.
- `grid-template-columns` and `grid-template-rows` define track sizes. Values can be `px`, `%`, `fr`, `auto`, `repeat()` or `minmax()`.
- A `fr` unit takes a share of the space left over after fixed tracks.
- `grid-template-areas` gives named regions; `grid-area` places an item into a named region.
- `grid-template` is a shorthand for rows, columns and areas together.
- `gap`, `row-gap` and `column-gap` set spacing. `grid-column-gap` and `grid-row-gap` are older names and are listed as deprecated.
- `justify-items` and `align-items` place items inside their own cells.
- `justify-content` and `align-content` place the whole grid when extra space is free.
- `place-items`, `place-content` and `place-self` are shorthands for each pair of alignment properties.
- `grid-column` and `grid-row` place an item using start and end lines, or `span n`.
- Media queries can switch a layout to a single column on small screens.

## Syntax / example
```css
.container {
  display: grid;
  grid-template-columns: 100px 200px 1fr;
  gap: 15px 10px;
}
.item {
  grid-column: 1 / 3;
}
```

## Remember
- Grid works in two dimensions; Flexbox works in one.
- `1fr` takes the leftover share of space.
- `grid-area` can name a region defined in `grid-template-areas`.
- Prefer `row-gap` and `column-gap` over the deprecated `grid-row-gap` and `grid-column-gap`.
