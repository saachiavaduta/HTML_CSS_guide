# CSS Pseudo-Elements

Source: CSS/20.CSS_Pseudo_Elements

## Key points
- A pseudo-element styles a specific part of an element, or adds generated content, without writing an extra HTML element.
- The word "pseudo" means "not real": the content exists only in the rendered page.
- Pseudo-elements are written with a double colon (`::`). The older single-colon form (`:before`) still works.
- `::before` places generated content before the element's own content.
- `::after` places generated content after the element's own content.
- `::before` and `::after` need a `content` property to show anything; `content: ""` is enough for decorative shapes.
- `::first-line` styles the first line of a block-level element, and it adapts when the text wraps.
- `::first-letter` styles the first letter, which is the usual way to make a drop cap.
- `::selection` styles the part of the text a user has highlighted, and it supports only a few properties such as `color` and `background`.
- `::first-line` and `::first-letter` apply only to block-level elements.
- Common uses are icons, decorative lines, overlays, tooltips, and quotation marks.

## Syntax / example
```css
.note::before { content: "> "; color: gold; }

.card { position: relative; }
.card::after {
  content: "";
  position: absolute;
  inset: 0;
  background: rgba(0, 0, 0, 0.4);   /* overlay over the card */
}
```

## Remember
- `::before` and `::after` do nothing without the `content` property.
- A pseudo-class (single colon) describes a state; a pseudo-element (double colon) targets a part of an element or generated content.
- Give the parent `position: relative` when an `::after` overlay or badge must be placed with `position: absolute`.
