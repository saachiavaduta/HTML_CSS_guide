# CSS Dropdown Menus

Source: CSS/24.CSS_Dropdown

## Key points
- A dropdown shows a hidden list of links when the user hovers over a parent link.
- The parent `li` gets `position: relative`, so the hidden list can be placed under it.
- The hidden box (`.dropdown-content`) starts with `display: none` and is set to `position: absolute`.
- `.dropdown:hover .dropdown-content { display: block; }` makes the box appear on hover.
- Three main types: basic dropdown (one level), multi-level dropdown (submenus inside submenus), and mega menu (wide panel with columns).
- Multi-level menus place a nested dropdown inside `.dropdown-content`, and move it with `left: 100%; top: 0;`.
- Mega menus use a wide `.dropdown-content` with `display: flex` or `display: grid` to lay out columns.
- Transitions such as opacity and transform can add a fade or slide effect.
- `z-index` helps make sure the dropdown appears above other content.
- Dropdowns are useful for grouping related links and saving space in a navbar.

## Syntax / example
```css
.dropdown {
  position: relative;
}
.dropdown-content {
  display: none;
  position: absolute;
  min-width: 160px;
}
.dropdown:hover .dropdown-content {
  display: block;
}
```

## Remember
- The parent needs `position: relative`; the dropdown box uses `position: absolute`.
- The box is hidden by default and shown with `:hover`.
- Multi-level menus position the inner box with `left: 100%`.
- Mega menus use flex or grid for their columns.
