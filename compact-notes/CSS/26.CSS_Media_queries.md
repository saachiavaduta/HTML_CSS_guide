# CSS Media Queries

Source: CSS/26.CSS_Media_queries

## Key points
- A media query applies CSS only when a condition about the device or screen is true.
- Syntax starts with `@media`, then an optional media type, then a feature in brackets, then a block of rules.
- Media types: `all` (default when omitted), `screen` (devices with screens), and `print` (printing or print preview).
- Common features: `width`, `min-width`, `max-width`, `height`, `min-height`, `max-height`, and `orientation` (`portrait` or `landscape`).
- `min-width` applies at or above a value; `max-width` applies at or below a value.
- Conditions combine with `and`; a comma acts as "or", and `not` negates a query.
- Mobile-first design sets base styles for small screens and uses `min-width` to add styles for larger screens.
- Typical breakpoints in the notes: mobile up to 576px, tablet 577px to 768px, desktop from 769px.
- `print` styles can hide elements (for example with `display: none`) or change font size for paper.
- Media queries are supported in all modern browsers.

## Syntax / example
```css
body {
  font-size: 16px;
}
@media screen and (max-width: 600px) {
  body {
    font-size: 14px;
  }
}
```

## Remember
- The syntax is `@media type and (feature: value) { ... }`.
- `max-width` targets narrower screens; `min-width` targets wider screens.
- `screen` targets displays and `print` targets printed output.
- Mobile-first design uses `min-width` in media queries.
