# CSS Units

Source: CSS/25.CSS_Units

## Key points
- CSS units measure sizes for properties such as width, height, font-size, margin and padding.
- Units are either absolute (fixed) or relative (based on something else).
- Absolute units include `px`, `cm`, `mm` and `in`; they do not change with the screen size.
- Viewport units: `vw` (percent of viewport width), `vh` (percent of viewport height), `vmin` (smaller side), `vmax` (larger side).
- Font-based units: `rem` (based on the root element's font size), `em` (based on font size), `ex` (height of the letter x).
- `rem` stays consistent across the page because it always uses the root font size.
- Percentage (`%`) is relative to the parent's matching value, such as its width for `width`, or its font size for `font-size`.
- For padding and margin, a percentage is based on the parent's width, not its height.
- Relative units suit responsive designs, because they scale with the page or parent.
- Modern browsers support all of these units, though older ones may have limited `vmin`, `vmax` or `ex` support.

## Syntax / example
```css
html {
  font-size: 16px;
}
.rem-spacing p {
  margin-bottom: 1.5rem;
}
.vw-font {
  font-size: 5vw;
}
```

## Remember
- `px`, `cm`, `mm` and `in` are absolute; `%`, `em`, `rem`, `vw` and `vh` are relative.
- `rem` uses the root (html) font size; `em` uses the element's font size.
- `vw` and `vh` are percentages of the browser window's width and height.
- Percentages are relative to the parent element.
