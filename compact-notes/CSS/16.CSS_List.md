# CSS List

Source: CSS/16.CSS_List

## Key points
- `list-style-type` picks the marker: `disc`, `circle`, `square`, `decimal`, `lower-roman`, `upper-roman`, `lower-alpha`, `upper-alpha`, `none`.
- A custom marker can be a quoted Unicode character, e.g. `'\2713'`.
- `list-style-image` replaces the marker with an image; `list-style-type` is used if the image fails.
- `list-style-position`: `outside` (default, marker hangs outside the text) or `inside` (marker is part of the text flow).
- `list-style` shorthand: `type position image` (any order, any subset).
- `list-style-type: none` removes markers, useful for menus and card grids.
- Marker colour can be set with `::marker`.

## Syntax / example
```css
ul.menu {
  list-style: none;
  padding: 0;
  display: flex;
}
ul.tasks {
  list-style-type: '\2713';
}
ol.steps {
  list-style-type: lower-roman;
  list-style-position: inside;
}
li::marker {
  color: #ff4500;
}
```

## Remember
- Nested lists can use different marker types.
- Use `padding: 0` to remove the default list indent when building menus.
- `::marker` styles the bullet or number colour separately from the text.
