# Introduction to CSS

Source: CSS/01.Introduction_to_CSS

## Key points
- CSS (Cascading Style Sheets) describes how HTML content is presented: layout, colors, fonts and overall look.
- Keeping styling in CSS separates content from design, which helps accessibility and flexibility.
- A CSS rule has a selector (what to style) and a declaration block in curly braces.
- Each declaration is a property and a value, joined by a colon and ended with a semicolon.
- Three ways to add CSS: inline (`style` attribute), internal (`<style>` in the head), external (linked `.css` file).
- Inline CSS is handy for one-off changes but mixes content with presentation, so it is harder to maintain.
- Internal CSS suits styling a single page.
- External CSS is the most efficient choice for large websites because it is reusable.

## Syntax / example
```css
h1 {
  color: blue;
  font-size: 24px;
}
```
```html
<link rel="stylesheet" href="styles.css">
```

## Remember
- Rule = selector + declaration block; declaration = property: value;
- Every declaration ends with a semicolon.
- Name the three ways to apply CSS: inline, internal, external.
- External CSS is the best choice for large sites.
