# CSS Comments

Source: CSS/03.CSS_Comments

## Key points
- Comments add notes inside a CSS file to explain the code.
- Browsers ignore comments, so they do not change how the page looks.
- Syntax: text placed between `/*` and `*/`.
- A comment can fit on one line or span several lines.
- Main uses: documenting styles, debugging (switching off a rule without deleting it), organizing sections, and helping other developers.
- Good practice: keep wording clear and short, comment only complex or non-obvious code, and place the comment above or beside the code it describes.
- Comments cannot be nested inside each other; a second `/*` inside a comment breaks it.
- Keep comments up to date when the code changes.

## Syntax / example
```css
/* Temporarily disable background image for testing */
/*
.hero {
  background-image: url('hero.jpg');
}
*/
.hero {
  background-color: #f0f0f0;
}
```

## Remember
- CSS comments start with `/*` and end with `*/`.
- Browsers ignore comments.
- Comments cannot be nested.
- Commenting out a rule is a simple way to debug.
