# CSS Display

Source: CSS/15.CSS_Display

## Key points
- `display` controls how an element participates in layout.
- `block`: starts on a new line and takes the full available width.
- `inline`: stays in the text flow; width and height are ignored.
- `inline-block`: flows inline but respects width, height, and margins.
- `none`: removes the element from layout entirely.
- `flex`: arranges children in a row or column (flexbox).
- `grid`: arranges children in rows and columns (grid).
- `contents`: removes the element's own box but keeps its children in layout; older browsers may not support it.

## Syntax / example
```css
nav span {
  display: block;
}
.badge {
  display: inline-block;
  width: 100px;
  padding: 10px;
}
.hidden {
  display: none;
}
```

## Remember
- `display: none` removes the element from layout; `visibility: hidden` keeps its space.
- Block elements stack; inline elements sit side by side.
- `width` and `height` have no effect on plain inline elements.
