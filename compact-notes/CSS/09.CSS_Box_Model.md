# CSS Box Model

Source: CSS/09.CSS_Box_Model

## Key points
- Every HTML element is a rectangular box made of four layers.
- From inside out: content (set by width and height), padding, border, margin.
- Padding and margin each have shorthand and per-side properties; border has the `border` shorthand and per-part properties.
- The margin is the outermost layer, the space outside the border.
- `box-sizing: border-box` makes the width include padding and border, so a 200px box stays 200px in total.
- Vertical margin collapse also applies in the box model: adjacent margins combine into the larger one.
- A max-width with auto side margins can center a responsive box.

## Syntax / example
```css
div {
  box-sizing: border-box;
  width: 200px;
  height: 100px;
  padding: 20px;
  border: 5px solid blue;
  margin: 30px;
}
```

## Remember
- Layer order, inside to outside: content, padding, border, margin.
- `border-box` keeps padding and border inside the set width.
- Margins between two stacked boxes collapse to the larger value.
- Padding sits inside the border; margin sits outside it.
