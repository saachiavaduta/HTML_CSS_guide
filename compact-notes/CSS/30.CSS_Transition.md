# CSS Transitions

Source: CSS/30.CSS_Transition

## Key points
- A transition changes a property gradually over time instead of jumping to the new value.
- A transition needs a trigger, such as `:hover`, `:focus`, or a JavaScript change.
- `transition-property` picks which property animates. `all` covers every animatable property; `none` turns transitions off.
- `transition-duration` sets how long the change takes. `0s` disables it.
- `transition-timing-function` sets the speed curve: `ease` (default), `linear`, `ease-in`, `ease-out`, `ease-in-out`, `cubic-bezier()` or `steps()`.
- `transition-delay` waits before the change starts. A negative delay starts partway through.
- The `transition` shorthand order is: property, duration, timing function, delay.
- Separate several transitions with commas.
- Not every property can transition. `display` cannot.
- Naming specific properties is usually better for performance than using `all`.

## Syntax / example
```css
.box {
  width: 100px;
  transition: width 0.5s ease 0.2s;
}
.box:hover {
  width: 150px;
}
```

## Remember
- Shorthand order: property, duration, timing function, delay.
- Default timing function is `ease`; default delay is `0s`.
- Transitions run only when a state changes. Animations can run on their own.
- `display` is not animatable with a transition.
