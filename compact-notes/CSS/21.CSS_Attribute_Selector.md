# CSS Attribute Selectors

Source: CSS/21.CSS_Attribute_Selector

## Key points
- Attribute selectors style elements based on whether an attribute exists or what value it holds.
- `[attribute]` matches any element that has the attribute, whatever its value.
- `[attribute="value"]` matches only when the value is exactly the same.
- `[attribute~="value"]` matches when one space-separated word in the value equals the given word.
- `[attribute*="value"]` matches when the value contains the given text anywhere inside it.
- `[attribute^="value"]` matches when the value begins with the given text.
- `[attribute$="value"]` matches when the value ends with the given text.
- They work on many attributes, including `href`, `src`, `type`, `target`, `alt`, `title`, and custom `data-*` attributes.
- Attribute selectors work in modern browsers, including Chrome, Firefox, Safari, and Edge.

## Syntax / example
```css
[title] { color: blue; }                          /* has a title attribute */
input[type="text"] { background-color: lightyellow; }  /* exact match */
[class~="highlight"] { background-color: yellow; }     /* one word in class list */
a[href*="example"] { font-weight: bold; }         /* "example" anywhere in href */
a[href^="https"] { color: green; }                /* href starts with https */
img[src$=".jpg"] { opacity: 0.8; }                /* src ends with .jpg */
```

## Remember
- `^=` means starts with, `$=` means ends with, `*=` means contains anywhere, and `~=` means a whole word in a space-separated list.
- `[attr]` checks only that the attribute is present; `[attr="value"]` requires an exact match.
- Quote the value inside the brackets, as in `[type="text"]`.
