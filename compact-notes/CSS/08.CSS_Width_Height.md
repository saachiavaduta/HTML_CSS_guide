# CSS Width, Height and Max-Width

Source: CSS/08.CSS_Width_Height

## Key points
- `width` sets the content area's width; padding, border and margin are not included unless `box-sizing: border-box` is used.
- `height` sets the content area's height in the same way.
- Both accept length units (px, %, vw, vh, rem, em) plus `auto` (default; the browser decides) and `inherit`.
- Width applies to block and inline-block elements; inline elements ignore it. Height has a similar rule for inline elements.
- Percentage width is relative to the parent's width.
- A percentage height needs the parent to have an explicit height.
- `max-width` caps how wide an element can grow, which helps responsive layouts. Its default is `none`, and it cannot be negative.
- `max-width` overrides `width` when the element would otherwise be wider than the cap.
- `width`, `height` and `max-width` are each set by their own property.

## Syntax / example
```css
div {
  width: 80%;
  max-width: 500px;
  height: auto;
}
div.wide {
  width: 100%;
  max-width: 600px;
  margin: 0 auto;
}
```

## Remember
- Default `width` and `height` are `auto`.
- `max-width` caps width and has no negative values.
- Percentage width is based on the parent.
- Viewport units: vw is width, vh is height.
