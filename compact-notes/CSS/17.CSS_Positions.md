# CSS Positions

Source: CSS/17.CSS_Positions

## Key points
- The `position` property decides where an element is placed on the page.
- The five values are `static`, `relative`, `absolute`, `fixed`, and `sticky`.
- `static` is the default, and `top`, `right`, `bottom`, `left` do nothing to it.
- `relative` moves an element away from its normal spot, but the original space stays reserved.
- `absolute` takes the element out of the normal flow, so nearby elements ignore it.
- An `absolute` element is placed against its nearest ancestor that has a position other than `static`.
- If no such ancestor exists, it falls back to the page's initial containing block (the viewport).
- `fixed` is placed against the viewport and stays in place while the page scrolls.
- `sticky` acts like `relative` until a scroll point is reached, then it behaves like `fixed`.
- `top`, `right`, `bottom`, and `left` are the offset values used with positioned elements.
- `z-index` controls which positioned element appears on top when they overlap.

## Syntax / example
```css
.box {
  position: relative;
  top: 20px;     /* moves down 20px from its normal place */
  left: 30px;    /* moves right 30px */
}

.parent {
  position: relative;   /* reference point for the child */
}

.child {
  position: absolute;
  top: 10px;
  right: 20px;          /* 10px from top and 20px from right of .parent */
}
```

## Remember
- `relative` keeps the element's space in the layout; `absolute` and `fixed` remove it from the flow.
- To place an `absolute` child inside a box, give the box `position: relative`.
- `fixed` is measured from the viewport; `sticky` switches from relative to fixed on scroll.
