# CSS Pseudo-Classes

Source: CSS/19.CSS_Pseudo_Class

## Key points
- A pseudo-class is a keyword added to a selector to style an element based on its state, its position, or what the user does to it.
- Pseudo-classes work without adding any extra class or ID to the HTML.
- `:hover` applies styles while a pointer (such as a mouse) is over the element.
- `:focus` applies styles when an element is selected for input, by keyboard or click, such as a form field.
- `:first-child` matches the first element among its siblings.
- `:last-child` matches the last element among its siblings.
- `:nth-child(n)` matches siblings by their position, using a number, a keyword, or a pattern.
- Common `:nth-child` keywords are `odd` and `even`; patterns such as `3n` repeat every third item.
- Pseudo-classes add to selector specificity, so combine them with care.
- Make `:focus` styles clearly visible, because keyboard users depend on them.

## Syntax / example
```css
.btn:hover { background-color: #007bff; color: white; }
.input:focus { outline: 2px solid blue; }
.list li:first-child { font-weight: bold; }
.items li:nth-child(even) { background-color: #f0f0f0; }
```

## Remember
- Pseudo-classes use a single colon and describe a state or position of an existing element.
- `:nth-child(even)` or `:nth-child(odd)` is the usual way to make zebra-striped rows.
- Do not remove the `:focus` style without providing a visible replacement.
