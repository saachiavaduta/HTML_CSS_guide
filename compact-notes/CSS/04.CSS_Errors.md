# Common CSS Errors

Source: CSS/04.CSS_Errors

## Key points
- Syntax errors: a missing semicolon or curly brace can make a rule fail. Fix by ending each declaration with `;` and checking braces. An editor with syntax highlighting helps spot them.
- Wrong selector: a class (`.`) used where an ID (`#`) is needed, or a misspelled selector, means the style never applies. Check the symbol and the exact name against the HTML.
- Specificity: when rules clash, the more specific rule wins. The order named in the notes is inline, then ID, then class, then element.
- Invalid values: a bad value such as `largepx` is ignored. Use a valid value with a proper unit, such as `16px`.
- Debugging: browser developer tools show which styles apply; a CSS validator checks the code.

## Syntax / example
```css
/* Incorrect: missing semicolon */
p {
  color: blue
}

/* Correct */
p {
  color: blue;
}
```

## Remember
- Every declaration needs a semicolon.
- Class uses `.`, ID uses `#`.
- Specificity order: inline > ID > class > element.
- Invalid values are ignored, so check units such as `px`.
