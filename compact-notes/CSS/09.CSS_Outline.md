# CSS Outline

Source: CSS/10.CSS_Outline

## Key points
- An outline is a line drawn around an element, outside its border.
- Outlines do not take up space, so they never change the element's size or layout.
- Outlines may overlap neighboring content.
- Three parts: `outline-width` (px, thin, medium, thick), `outline-style`, `outline-color` (name, hex, rgb, or `invert`).
- Shorthand: `outline: width style color;`
- Styles match the border styles (none is the default), though groove, ridge, inset and outset can look different across browsers.
- Outlines apply to all four sides at once; there is no per-side control.
- Outlines are often used as focus indicators, which helps keyboard users and accessibility.
- Borders take up space and can be set per side and rounded with `border-radius`; outlines do not take up space and may not follow rounded corners in every browser.

## Syntax / example
```css
div {
  border: 5px solid black;
  outline: 3px solid blue;
}
button:focus {
  outline: 3px dotted orange;
}
```

## Remember
- Outline is drawn outside the border and does not affect layout.
- Shorthand order: width, style, color.
- Outlines cannot be set per side; borders can.
- Default outline style is none.
