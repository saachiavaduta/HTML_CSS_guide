# CSS Navigation Bars

Source: CSS/22.CSS_Navbar

## Key points
- A navbar is usually a `<nav>` holding a `<ul>` of `<li>` links, styled with CSS.
- Three main kinds: horizontal (links side by side), vertical (links stacked, often a sidebar), and dropdown (submenus that open on hover).
- Horizontal bars are commonly built with `display: flex`, though `float` or `inline-block` also work.
- Remove the default bullets with `list-style-type: none` and clear the list's default margin and padding.
- Make each link a block (`display: block`) with padding so the whole box is clickable.
- Use `:hover` to change the link background when the mouse is over it.
- A sticky navbar uses `position: sticky; top: 0;` to stay at the top while scrolling.
- Vertical bars can use a set `width`, or `flex-direction: column` on a flex list.
- Floated navbars need a clearfix so the parent does not collapse.
- Flexbox is preferred over float for modern layouts.

## Syntax / example
```css
.nav ul {
  display: flex;
  list-style-type: none;
  margin: 0;
  padding: 0;
}
.nav li a {
  display: block;
  padding: 14px 16px;
  text-decoration: none;
}
```

## Remember
- A horizontal navbar is typically a flex list with `display: block` links.
- `:hover` on the link gives the mouse-over effect.
- Use `position: sticky; top: 0;` to keep a navbar visible while scrolling.
- Floated items need a clearfix to stop the parent collapsing.
