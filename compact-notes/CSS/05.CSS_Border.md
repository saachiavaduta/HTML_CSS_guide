# CSS Borders

Source: CSS/05.CSS_Border

## Key points
- A border is the line around an element, between its padding and margin.
- `border-style` sets the look of the line: solid, dashed, dotted, double, groove, ridge, inset, outset, none (default) or hidden.
- `border-width` sets thickness in px, or with the keywords thin (1px), medium (3px) or thick (5px).
- `border-color` takes a color name, hex, rgb, rgba, hsl or hsla value.
- `border-style` must be set for width and color to show.
- The `border` shorthand combines width, style and color in one line; the order is flexible and any part can be left out (the missing parts take their default).
- Individual sides can be set with `border-top`, `border-right`, `border-bottom` or `border-left`.
- Groove and ridge (and inset and outset) are 3D-looking styles that depend on the color.

## Syntax / example
```css
div {
  border: 2px solid black;
  padding: 10px;
}
aside {
  border-style: solid;
  border-width: 2px 4px 6px 8px; /* top, right, bottom, left */
  border-color: black;
}
```

## Remember
- Order of the shorthand is flexible; `border-style` is the part that makes the border visible.
- `border-style` is required before width or color has any effect.
- Width keywords: thin = 1px, medium = 3px, thick = 5px.
- Default border style is none.
