# CSS Margin and Padding

Source: CSS/07.CSS_Margin_Padding

## Key points
- Margin is the space outside an element's border; it separates the element from its neighbors.
- Padding is the space inside an element, between its content and its border.
- Margin accepts px, %, cm, `auto` or negative values; `margin: auto` is used to center block elements horizontally.
- Padding cannot be negative.
- Shorthand order is top, right, bottom, left. One value applies to all sides; two values set top/bottom then left/right; three values set top, then left/right, then bottom; four values set each side.
- Individual properties (`margin-top`, `padding-left`, etc.) set one side at a time.
- Margin collapse: vertical margins of adjacent block elements merge into the larger of the two, not their sum.
- Padding does not collapse. It increases total size unless `box-sizing: border-box` is used.
- Margin collapse can be stopped with padding, a border, or `display: flow-root` on the parent.

## Syntax / example
```css
div {
  margin: 10px 20px 30px 40px;
  padding: 15px;
}
div.centered {
  width: 200px;
  margin: 0 auto;
}
```

## Remember
- Margin = outside, padding = inside.
- Collapsed vertical margins take the larger value (20px and 30px give 30px).
- Padding cannot be negative.
- `margin: 0 auto` centers a block element.
