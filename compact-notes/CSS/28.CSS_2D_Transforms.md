# CSS 2D Transforms

Source: CSS/28.CSS_2D_Transforms

## Key points
- The `transform` property changes how an element looks in 2D space without changing the layout around it.
- `translate(x, y)` moves an element; positive x goes right, positive y goes down. If y is left out, it is 0.
- `rotate(angle)` turns an element; positive degrees turn clockwise, negative turn counterclockwise.
- `scaleX()`, `scaleY()` and `scale(x, y)` resize using unitless factors: above 1 stretches, below 1 shrinks, negative flips.
- `skewX()`, `skewY()` and `skew(x, y)` tilt an element by an angle in deg, rad or turn.
- `matrix(a, b, c, d, tx, ty)` combines several effects in one six-number function.
- `transform-origin` sets the pivot point; the default is the center.
- Multiple transforms can be listed in one value and are applied in order.
- Transforms are not inherited; use `inherit` to copy the parent's value.
- Heavy skew or negative scaling can distort text, so use them with care.

## Syntax / example
```css
.box {
  transform: translate(50px, 20px) rotate(45deg);
  transform-origin: top left;
}
```

## Remember
- `translate` moves, `rotate` turns, `scale` resizes, `skew` tilts.
- Positive `rotate` is clockwise; positive `translate` y moves down.
- A scale factor of 1 means no change; `scale(-1)` flips.
- `transform-origin` defaults to `center`.
