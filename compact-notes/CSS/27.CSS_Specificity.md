# CSS Specificity

Source: CSS/27.CSS_Specificity

## Key points
- Specificity decides which rule wins when several rules target the same element.
- A more specific selector beats a less specific one, whatever its position in the file.
- If two selectors have equal specificity, the rule written last wins.
- Specificity is written as four numbers (a,b,c,d): inline style, IDs, classes/attributes/pseudo-classes, elements/pseudo-elements.
- Element selectors (such as `p`) score (0,0,0,1).
- Class, attribute and pseudo-class selectors (such as `.highlight`, `[type="text"]`, `:hover`) score (0,0,1,0).
- ID selectors (such as `#header`) score (0,1,0,0).
- Inline styles (in a `style` attribute) score (1,0,0,0).
- `!important` overrides normal rules; use it sparingly because it makes debugging harder.
- Example: `#id .class p` scores (0,1,1,1); scores are compared left to right.

## Syntax / example
```css
p {
  color: blue;        /* (0,0,0,1) */
}
.highlight {
  color: yellow;      /* (0,0,1,0) wins over p */
}
```

## Remember
- Order of strength: `!important`, inline style, ID, class/attribute/pseudo-class, element.
- Equal specificity: the last rule in the file wins.
- Compare the four numbers from left to right.
- Avoid overusing IDs and `!important`.
