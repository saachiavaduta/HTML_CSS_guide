# CSS Links

Source: CSS/13.CSS_Links

## Key points
- Links are `<a>` elements; style them with `color`, `text-decoration`, and `background-color`.
- Browsers underline links by default; `text-decoration: none` removes it.
- Link pseudo-classes: `:link` (unvisited), `:visited`, `:hover`, `:active`.
- Order matters: `:link`, `:visited`, `:hover`, `:active` (remember "LoVe HAte").
- `background-color` on a link with padding makes it look like a button.
- `cursor` sets the mouse pointer over an element: `default`, `pointer` (hand), `auto`, `text` (I-beam), `move`, `not-allowed`, `wait`, `progress`.

## Syntax / example
```css
a:link { color: blue; text-decoration: none; }
a:visited { color: purple; }
a:hover { color: red; text-decoration: underline; }
a:active { color: green; }

.btn {
  background-color: lightblue;
  padding: 5px;
  cursor: pointer;
}
```

## Remember
- Keep the pseudo-class order: `:link`, `:visited`, `:hover`, `:active`.
- `:visited` styling is limited for privacy reasons; only some properties apply.
- `cursor: pointer` signals clickable elements.
- Link styling changes text and background, not the layout.
