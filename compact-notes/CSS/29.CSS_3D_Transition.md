# CSS 3D Transforms

Source: CSS/29.CSS_3D_Transition

## Key points
- 3D transforms move or turn an element through depth (the z-axis), not only across the flat screen.
- `perspective` sets how far the viewer sits from the element. Small values give a strong 3D look; large values give a softer one.
- Put `perspective` on the parent so all of its children share one 3D space.
- `translate3d(x, y, z)` moves an element on three axes. A positive z moves it toward the viewer.
- `scale3d(x, y, z)` resizes on each axis using plain numbers. `1` means no change.
- `rotateX()` flips around the horizontal axis, `rotateY()` around the vertical axis.
- `rotateZ()` turns the element on the screen plane, the same idea as 2D `rotate()`.
- `rotate3d(x, y, z, angle)` rotates around a custom axis set by the x, y and z values.
- Depth effects only show when a `perspective` value is present.
- `transform-style: preserve-3d` on the parent keeps children in 3D positions.
- `transform-origin` moves the pivot point used for rotation and scaling.

## Syntax / example
```css
.perspective-parent {
  perspective: 500px;
}
.box {
  transform: rotateY(45deg);
}
.slide-box {
  transform: translate3d(50px, 20px, 30px);
}
```

## Remember
- Depth needs `perspective`, set on the parent or inside `perspective()`.
- A smaller perspective value makes the 3D effect stronger.
- `rotateZ()` is the same as 2D `rotate()`.
- Use `transform-style: preserve-3d` when child elements must stay in 3D space.
