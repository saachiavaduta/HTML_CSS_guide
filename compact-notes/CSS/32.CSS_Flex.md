# CSS Flexbox

Source: CSS/32.CSS_Flex

## Key points
- Flexbox is a one-dimensional layout model. It arranges items along a single row or column at a time.
- The flex container is the parent with `display: flex`. Its direct children are the flex items.
- The main axis follows the direction set by `flex-direction`. The cross axis runs at a right angle to it.
- `flex-direction` takes `row` (default), `row-reverse`, `column` or `column-reverse`.
- `flex-wrap` decides whether items move to a new line: `nowrap` (default), `wrap` or `wrap-reverse`.
- `flex-flow` is a shorthand for `flex-direction` and `flex-wrap`.
- `justify-content` aligns items on the main axis. `align-items` aligns them on the cross axis.
- `align-content` spaces out wrapped lines on the cross axis.
- `gap`, `row-gap` and `column-gap` set spacing between items.
- Item properties: `order` (default 0, lower shows first), `flex-grow` (default 0), `flex-shrink` (default 1), `flex-basis` (default `auto`).
- The `flex` shorthand sets grow, shrink and basis together. `align-self` overrides `align-items` for one item.

## Syntax / example
```css
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
.item {
  flex: 1 1 200px;
}
```

## Remember
- `justify-content` works on the main axis; `align-items` works on the cross axis.
- Defaults: `flex-grow` 0, `flex-shrink` 1, `flex-basis` `auto`.
- `flex: 1` is a shorthand for grow, shrink and basis.
- Flexbox handles one direction at a time; use Grid for rows and columns together.
