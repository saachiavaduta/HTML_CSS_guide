# CSS Backgrounds

Source: CSS/06.CSS_Background

## Key points
- `background-color` fills the element with a color (name, hex, rgb, rgba, hsl or hsla). It also works as a fallback under an image.
- `background-image` takes a `url()` or a gradient; several images can be layered with commas.
- `background-repeat` controls tiling: repeat (default), repeat-x, repeat-y, no-repeat, space or round.
- `background-attachment`: scroll (default) moves with content, fixed stays put, local moves with the element's own scrolling content.
- `background-position` sets the starting point with keywords, percentages or pixels.
- `background-size`: auto (default), a length, cover (fills and may crop) or contain (fits without cropping).
- `background-origin` sets the positioning area: padding-box (default), border-box or content-box.
- `background-clip` sets where the background is visible: border-box (default), padding-box or content-box.
- The `background` shorthand puts these together; a slash joins position and size.

## Syntax / example
```css
div {
  background-color: lightblue;
  background-image: url('flower.png');
  background-repeat: no-repeat;
}
div.hero {
  background: #f0f0f0 url('tile.png') center center no-repeat fixed;
}
```

## Remember
- `cover` may crop the image; `contain` never crops.
- In the shorthand, write position and size as `position/size`.
- Use `background-color` as a fallback for an image.
- Default repeat is `repeat`; default attachment is `scroll`.
