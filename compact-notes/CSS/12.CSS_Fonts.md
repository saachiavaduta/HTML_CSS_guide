# CSS Fonts

Source: CSS/12.CSS_Fonts

## Key points
- `font-family` picks the typeface; list fallbacks separated by commas and end with a generic family.
- Font names containing spaces need quotes, e.g. `"Times New Roman"`.
- Generic families: `serif`, `sans-serif`, `monospace`, `cursive`, `fantasy`.
- Web-safe fonts (Arial, Verdana, Georgia, Times New Roman, Courier New) are available on most systems.
- The browser uses the first installed font in the list; if none exist, it uses the generic family.
- `font-style`: `normal`, `italic` (true italic variant), `oblique` (slanted normal font).
- `font-size`: `px` for fixed size; `em`/`rem` relative to parent/root; keywords like `small`, `large`.
- Google Fonts are loaded with a `<link>` tag or `@import`, then used in `font-family`; needs internet.
- Font pairing: combine a serif with a sans-serif, or use different weights of one family; limit to 2-3 fonts.
- `font` shorthand: `style weight size/line-height family`. Size and family are required.

## Syntax / example
```css
body {
  font-family: Arial, Helvetica, sans-serif;
  font-size: 1rem;
}
h2 {
  font: italic bold 20px/1.4 Georgia, serif;
}
```

## Remember
- Always end `font-family` with a generic family as a fallback.
- Shorthand requires at least font-size and font-family.
- `italic` uses a real italic face when available; `oblique` slants the regular face.
- Google Fonts need the `<link>` before the font is used.
