# CSS Float

Source: CSS/23.CSS_Float

## Key points
- `float` pushes an element to the left or right edge of its parent.
- Text and inline content wrap around a floated element.
- A floated element is taken out of normal flow, so later elements can move up beside it.
- Allowed `float` values are `none` (default), `left`, `right`, `initial`, and `inherit`.
- `clear` stops an element from sitting beside floats on the chosen side.
- Allowed `clear` values are `none` (default), `left`, `right`, `both`, `initial`, and `inherit`.
- `clear: both` forces an element below all floats on both sides.
- When every child is floated, the parent can lose its height (collapse).
- A clearfix (or `overflow: auto` on the parent) fixes parent collapse.
- Typical uses: wrapping text around an image, simple two-column layouts, and horizontal menus.
- Flexbox or Grid are usually better for complex layouts.

## Syntax / example
```css
.float-img {
  float: left;
  width: 150px;
  margin-right: 10px;
}
.clear {
  clear: both;
}
```

## Remember
- `float: left` or `float: right` moves an element to that side; text wraps around it.
- `clear: both` makes the next element start below the floats.
- A clearfix fixes parent collapse caused by floated children.
