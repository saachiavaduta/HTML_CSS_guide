# CSS Combinators

Source: CSS/18.CSS_Combinators

## Key points
- A combinator describes how two selectors relate to each other in the HTML tree.
- Combinators let you target elements by their place in the structure, so fewer classes or IDs are needed.
- Descendant combinator (a space): selects an element at any depth inside another element.
- Child combinator (`>`): selects only the direct children of an element, not deeper nested ones.
- Adjacent sibling combinator (`+`): selects the single element that comes right after a given sibling.
- General sibling combinator (`~`): selects every later sibling that shares the same parent, not just the next one.
- Siblings are elements that share the same parent element.
- Combinators count toward selector specificity, so check that the right elements are matched.
- All four combinators work in modern browsers.
- Keep the content order logical so screen-reader users follow the page correctly.

## Syntax / example
```css
.main-nav a { color: blue; }      /* any link inside .main-nav, at any depth */
.menu > li { font-weight: bold; } /* only the top-level list items of .menu */
h2 + p { color: green; }          /* the paragraph right after an h2 */
h1 ~ p { margin-left: 10px; }     /* every paragraph after an h1 at the same level */
```

## Remember
- Space means any depth; `>` means direct child only.
- `+` targets the very next sibling; `~` targets all later siblings.
- Nested children that are one level too deep are not matched by `>`.
