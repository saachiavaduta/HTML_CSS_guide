# CSS Selectors

Source: CSS/02.CSS_Selectors

## Key points
- Selectors pick which HTML elements a style applies to.
- Element selector: targets every element of a type (for example `p`, `h1`, `div`).
- ID selector: uses `#` plus the id name; an id should be unique, so it hits one element.
- Class selector: uses `.` plus the class name; many elements can share one class.
- Grouping selector: separates several selectors with commas so they share the same styles.
- Universal selector (`*`): targets every element; handy for global resets but has a broad effect, so use it carefully.
- A selector can be combined with others in one file, such as an element rule next to a class rule.

## Syntax / example
```css
#banner {
  background-color: yellow;
}
.alert {
  color: white;
}
h1, h3, .header {
  font-family: Helvetica;
}
```

## Remember
- `#` = ID (one element), `.` = class (many elements).
- Commas group selectors that share the same declarations.
- The universal selector `*` affects every element on the page.
- Element selectors style all matching tags.
