# CSS Table

Source: CSS/14.CSS-Table

## Key points
- Table borders: apply `border` to `table`, `th`, `td`.
- `border-collapse: collapse` merges neighbouring borders; `separate` (default) keeps them apart.
- `border-spacing` sets the gap between cell borders when borders are separate.
- `width` and `height` size the table or cells (`px`, `%`, `auto`).
- `text-align` sets horizontal alignment; `vertical-align` sets `top`, `middle`, `bottom`.
- Styling tools: `padding`, `border-bottom` for dividers, `:hover` for highlighting, `nth-child(odd/even)` for zebra stripes.
- Wide tables: wrap in a container with `overflow-x: auto` to scroll horizontally on small screens.

## Syntax / example
```css
table {
  width: 100%;
  border-collapse: collapse;
}
th, td {
  border: 1px solid black;
  padding: 10px;
  text-align: left;
}
tr:nth-child(even) {
  background-color: #f2f2f2;
}
.table-wrap {
  overflow-x: auto;
}
```

## Remember
- `border-collapse` must be `separate` for `border-spacing` to have effect.
- `vertical-align` needs a taller cell (e.g. `height`) to show a visible effect.
- Put wide tables inside a div with `overflow-x: auto`.
