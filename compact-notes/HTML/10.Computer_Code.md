# Computer Code Elements

Source: HTML/10.Computer_Code

## Key points
- Five elements mark up computer content: `code`, `pre`, `kbd`, `samp`, `var`.
- They are usually shown in a monospace font so technical text is easy to read.
- `code` is for short inline code inside a sentence (function names, commands, CSS properties).
- `pre` keeps spaces, tabs and line breaks exactly as typed; use it for multi-line code.
- `kbd` marks text the user types or presses (key shortcuts, typed commands).
- `samp` marks sample output from a program, script or system (messages, errors).
- `var` marks a variable or placeholder; it is italic by default.
- Pick the element by meaning, not just by how it looks.
- Write `<` and `>` as `&lt;` and `&gt;` inside code samples.
- CSS can style these elements, for example a dark background for `pre`.
- Add surrounding text so screen readers understand the context.

## Syntax / example
```html
<p>To copy text, press <kbd>Ctrl + C</kbd>.</p>
<p>Running <samp>pwd</samp> prints <samp>/home/user/project</samp>.</p>
<pre>
git init
git add .
</pre>
```

## Remember
- `pre` keeps whitespace and line breaks; `code` does not.
- `kbd` = user input, `samp` = program output, `var` = variable or placeholder.
