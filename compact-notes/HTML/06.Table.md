# Table

Source: HTML/06.Table

## Key points
- Tables organise data in rows and columns using `<table>`.
- `<tr>` defines a row; `<th>` a header cell (bold and centred by default); `<td>` a data cell.
- `<caption>` gives the table a title, usually shown above it.
- `<thead>`, `<tbody>`, `<tfoot>` group header, body and footer rows (semantic).
- `border` on `<table>` sets the border width in pixels (older attribute).
- `colspan` makes a cell span several columns; `rowspan` makes it span several rows.
- `scope="col"` or `scope="row"` on `<th>` says which cells the header describes.
- `headers` on `<td>` links a data cell to one or more `<th>` cells by their `id`.
- `scope` and `headers` help screen readers announce the right heading with each value.
- Use `scope` for most tables; add `headers` for complex tables where one cell belongs to several headers.

## Syntax / example
```html
<table border="1">
  <caption>Workshop Schedule</caption>
  <tr>
    <th scope="col">Workshop</th>
    <th scope="col">Date</th>
  </tr>
  <tr>
    <td>JavaScript Basics</td>
    <td>October 2025</td>
  </tr>
</table>
```

## Remember
- Rows are `<tr>`, headers `<th>`, data `<td>`.
- `colspan` = merge across columns; `rowspan` = merge down rows.
- `scope` is on `<th>`; `headers` is on `<td>`.
- `thead`/`tbody`/`tfoot` group the table parts.
