# Iframe

Source: HTML/09.Iframe

## Key points
- An iframe (inline frame) shows another HTML document inside your page, in a rectangular box.
- Typical content: other web pages, videos, maps.
- Main attributes: `src` (the URL), `width`, `height`, `name`, `frameborder`, `allow`, `title`.
- Give `name` to an iframe so a normal link can load its page inside that frame (via `target`).
- Browsers block features like autoplay, fullscreen and camera by default.
- The `allow` attribute grants those features; list only what you need, separated by semicolons.
- Always add a `title` for accessibility.
- Use `sandbox` for untrusted content.
- Percentage widths or CSS make an iframe responsive.
- Too many iframes on one page hurt performance.

## Syntax / example
```html
<iframe src="https://www.example.com" width="100%" height="400" title="Example Website"></iframe>
```

```html
<a href="https://www.example.com" target="myframe">Visit Example.com</a>
<iframe name="myframe" width="100%" height="300" title="Targeted Frame"></iframe>
```

## Remember
- An iframe embeds another document; `allow` gives it permissions.
- Without the right `allow` value, YouTube autoplay or fullscreen may not work.
- Always include a `title` attribute.
