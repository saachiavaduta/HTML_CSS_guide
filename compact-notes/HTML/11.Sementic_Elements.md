# Semantic Elements

Source: HTML/11.Sementic_Elements

## Key points
- Semantic elements describe the meaning of a page part; they came with HTML5.
- They help browsers, search engines, developers and screen readers understand the page.
- `article` holds self-contained content that could stand alone, such as a blog post.
- `aside` holds content only loosely related to the main text, such as a sidebar.
- `header` and `footer` hold introductory or closing content for a page or section.
- `main` holds the core content; use only one per page.
- `nav` groups major navigation links, such as a menu.
- `section` groups related content, normally with a heading.
- `figure` and `figcaption` pair self-contained media with a caption.
- `details` and `summary` make an expandable block; `summary` is the clickable heading.
- `mark` highlights text; `time` gives a date or time, with a machine-readable `datetime` attribute.
- Prefer these elements over generic `div` and `span` where they fit.

## Syntax / example
```html
<main>
  <article>
    <h2>The Benefits of Semantic HTML</h2>
    <p>Semantic HTML improves accessibility and SEO.</p>
  </article>
</main>

<details>
  <summary>What is HTML?</summary>
  <p>HTML is the standard markup language for web pages.</p>
</details>
```

## Remember
- Only one `main` per page.
- `article` = standalone content, `section` = thematic group with a heading, `aside` = related but indirect content.
- Use `datetime` on `time` for a machine-readable date.
