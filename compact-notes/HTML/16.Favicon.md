# Favicon

Source: HTML/16.Favicon

## Key points
- A favicon is the small icon shown in the browser tab next to the page title; it also appears in bookmarks.
- Use a small square image, 16x16 or 32x32 pixels.
- Save it as `favicon.ico` (most common) or `favicon.png`.
- Put the file in the same folder as the HTML file, usually the root folder.
- Link it inside `head` with `<link rel="icon">`.
- Set the `type` to match the format: `image/x-icon`, `image/png` or `image/svg+xml`.
- SVG is a modern option that stays sharp at any size.
- Keep the design simple, because details disappear at small sizes.
- Browsers look for `favicon.ico` automatically when no link is given.
- If the new icon does not appear, clear the cache or force a refresh (Ctrl + Shift + R).
- Common mistakes: putting the link outside `head`, and a wrong file path or file name.

## Syntax / example
```html
<head>
  <title>My First Website</title>
  <link rel="icon" href="favicon.ico" type="image/x-icon">
</head>
```

```html
<link rel="icon" href="favicon.png" type="image/png">
```

## Remember
- Favicon: square, 16x16 or 32x32, `.ico` or `.png` for best support.
- The `<link rel="icon">` tag goes inside `head`.
- The file path must match the file name exactly.
