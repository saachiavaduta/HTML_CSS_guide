# List

Source: HTML/07.List

## Key points
- `<ul>` is an unordered (bulleted) list.
- `<ol>` is an ordered (numbered) list.
- `<li>` is one item inside `<ul>` or `<ol>`.
- `<dl>` is a description list; `<dt>` is the term and `<dd>` its description.
- `type` on `<ul>` sets the bullet style (`disc`, `circle`, `square`); this attribute is deprecated.
- `type` on `<ol>` sets numbering: `1`, `A`, `a`, `I`, `i`.
- `start` on `<ol>` sets the first number or letter.
- `reversed` on `<ol>` counts downward.
- `value` on `<li>` (inside `<ol>` only) sets that item's number; later items continue from it.
- Lists can be nested: put a `<ul>` or `<ol>` inside an `<li>` to make a sublist.

## Syntax / example
```html
<ul type="circle">
  <li>Coding Gita Courses
    <ol type="a">
      <li>Python Basics</li>
      <li>Advanced JavaScript</li>
    </ol>
  </li>
</ul>

<ol type="1" start="2">
  <li>Introduction to Programming</li>
  <li>Advanced Python</li>
</ol>
```

## Remember
- `<ul>` = bullets, `<ol>` = numbers.
- Items always sit in `<li>`.
- `start`, `reversed` and `value` only apply to `<ol>`.
- `<dl>` pairs `<dt>` (term) with `<dd>` (description).
