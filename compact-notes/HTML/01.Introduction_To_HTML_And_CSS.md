# Introduction to HTML and CSS

Source: HTML/01.Introduction_To_HTML_And_CSS

## Key points
- HTML (HyperText Markup Language) builds the structure and content of a web page.
- HTML is a markup language, not a programming language.
- CSS (Cascading Style Sheets) controls how the content looks: colors, fonts, spacing, layout.
- HTML gives the skeleton; CSS gives the design. Together they make most websites.
- `<!DOCTYPE html>` must be the first line and tells the browser it is HTML5.
- `<html>` is the root element that wraps everything.
- `<head>` holds information about the page (not shown on it): meta tags, title, links.
- `<body>` holds all visible content.
- `<title>` text appears in the browser tab.
- A tag is a keyword in angle brackets; an element is opening tag + content + closing tag.
- Attributes add extra info inside the opening tag, as `name="value"`.
- Void (self-closing) tags such as `<br>`, `<hr>`, `<img>`, `<input>`, `<meta>`, `<link>` have no closing tag.

## Syntax / example
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My Webpage</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>This is my first HTML page.</p>
</body>
</html>
```

## Remember
- HTML = structure, CSS = style.
- Only `<body>` content is visible on the page.
- `<!DOCTYPE html>` is an instruction to the browser, not a tag.
- `<meta charset="UTF-8">` sets the character encoding.
