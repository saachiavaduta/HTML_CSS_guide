# Audio and Video Media

Source: HTML/14.Media

## Key points
- `audio` embeds sound such as music, podcasts or sound effects.
- `video` embeds video such as MP4, WebM or OGG files.
- `source` children give several formats so the browser can pick one it supports.
- `track` adds subtitles or captions to video (the best-practice notes also suggest it for audio).
- Shared audio attributes: `src`, `controls`, `autoplay`, `loop`, `muted`.
- Video adds `poster` (preview image), `width`, `height`, `playsinline` and `disablePictureInPicture`.
- `autoplay` usually needs `muted`, otherwise sound starts without the user asking.
- `playsinline` keeps mobile video inside the page instead of forcing fullscreen.
- `preload="metadata"` or `"none"` speeds up loading of large files.
- Put fallback text inside the element for browsers that do not support it.
- For responsive video, use a percentage width with a CSS `max-width`.

## Syntax / example
```html
<video controls width="640" poster="tutorial-preview.jpg">
  <source src="coding-tutorial.mp4" type="video/mp4">
  <source src="coding-tutorial.webm" type="video/webm">
  <track src="tutorial-subtitles.vtt" kind="subtitles" srclang="en" label="English">
  Your browser does not support the video tag.
</video>
```

## Remember
- Use several `source` elements for format fallback.
- Pair `autoplay` with `muted`.
- `poster` shows an image before playback; `track` provides captions for accessibility.
