# Paragraph and Heading Tags

Source: HTML/02.Paragraph_and_Heading_Tag

## Key points
- `<p>` defines a paragraph of text; browsers add space above and below it.
- `<p>` is a block-level element: it starts on a new line and takes the full width.
- Do not put block-level elements (headings, lists, other paragraphs) inside a `<p>`.
- Closing `</p>` is recommended in HTML5.
- Heading tags `<h1>` to `<h6>` define headings; `<h1>` is the most important, `<h6>` the least.
- Headings are block-level and show a clear page structure for readers and search engines.
- Use headings in logical order; avoid skipping levels without a reason.
- Normally a page has only one `<h1>`, used as the main title.
- Search engines give more weight to content in higher-level headings.
- `title`, `lang` and `dir` are common attributes on both `<p>` and headings.
- `align` is deprecated; use CSS (`text-align`) instead.

## Syntax / example
```html
<h1>Main Heading</h1>
<h2>Sub Heading</h2>
<p>This is a paragraph of text.</p>
```

## Remember
- `<p>` is for body text; headings are for document structure.
- Use one `<h1>` per page.
- Paragraphs and headings are block-level elements.
- Prefer CSS over the deprecated `align` attribute.
