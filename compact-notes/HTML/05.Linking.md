# Linking

Source: HTML/05.Linking

## Key points
- Links are made with the `<a>` (anchor) tag.
- `href` is the most important attribute; it holds the destination URL.
- `target` sets where the link opens; `title` gives a hover tooltip; `download` downloads the file instead of opening it.
- External links go to another website and usually start with `http://` or `https://`.
- Internal links go to a page or section on the same website; they can use relative paths like `courses.html`.
- `target` values: `_self` (same tab, default), `_blank` (new tab), `_parent` (parent frame), `_top` (whole window), or a custom frame name.
- A bookmark is an internal link to a spot on the same page.
- To make a bookmark: give the target an `id` (e.g. `<h2 id="workshops">`), then use `href="#workshops"`.
- `href="#top"` with `id="top"` on `<body>` gives a "back to top" link.

## Syntax / example
```html
<a href="https://codinggita.com" target="_blank">Visit Coding Gita</a>
<a href="courses.html">View Our Courses</a>

<h2 id="workshops">Workshops</h2>
<a href="#workshops">Go to Workshops</a>
```

## Remember
- `href` = where the link goes; `target` = where it opens.
- `_blank` opens a new tab; `_self` stays in the same tab.
- A bookmark needs both an `id` on the target and `#id` in the `href`.
- External = other site; internal = same site or same page.
