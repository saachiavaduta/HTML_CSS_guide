# Meta Tags

Source: HTML/15.Meta_Tags

## Key points
- Meta tags sit inside `head` and describe the page; they are not shown on the page itself.
- Search engines, browsers and social platforms all read them.
- `charset="UTF-8"` sets the character encoding.
- The `viewport` meta controls size and scale on mobile screens.
- `description` is a short summary that search engines may use in results.
- `keywords` has little effect on modern SEO.
- `robots` controls indexing and link following, e.g. `index, follow` or `noindex, nofollow`.
- `author`, `application-name` and `refresh` (via `http-equiv`) are other common tags.
- Open Graph tags (`property="og:..."`) control link previews on Facebook, LinkedIn and similar sites: `og:title`, `og:description`, `og:image`, `og:url`, `og:type`, `og:site_name`, `og:locale`.
- Twitter Card tags (`name="twitter:..."`) control previews on X/Twitter: `twitter:card`, `twitter:title`, `twitter:description`, `twitter:image`, `twitter:site`, `twitter:creator`.
- Card types include `summary`, `summary_large_image`, `player` and `app`.
- Suggested image sizes: 1200x630 for OG, 1200x628 for large image cards, 280x150 for summary cards.

## Syntax / example
```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="A short summary of the page.">
  <meta property="og:title" content="Title shown when shared">
  <meta name="twitter:card" content="summary_large_image">
</head>
```

## Remember
- Meta tags go in `head` and are invisible on the page.
- `viewport` makes a page scale correctly on phones.
- Open Graph tags use `property`; Twitter Card tags use `name`.
