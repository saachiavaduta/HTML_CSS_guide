# HTML Entities and Symbols

Source: HTML/12.Entities_And_Symbols

## Key points
- An entity starts with `&` and ends with `;`.
- Entities show reserved characters, special symbols and emojis.
- Three forms exist: named (`&copy;`), decimal (`&#169;`) and hexadecimal (`&#xA9;`).
- Reserved characters: `&lt;` gives `<`, `&gt;` gives `>`, `&amp;` gives `&`.
- Currency: `&euro;`, `&pound;`, `&yen;`.
- Math: `&ne;` (not equal), `&sum;` (summation), `&infin;` (infinity).
- Dashes: `&ndash;` (en dash) for ranges, `&mdash;` (em dash) for breaks in a sentence.
- `&nbsp;` is a non-breaking space that keeps words such as "10 km" together.
- Many emojis have no named entity, so use the numeric codes.
- Keep one format per project and add `aria-label` to emojis for screen readers.

## Syntax / example
```html
<p>Price: &euro;99.99</p>
<p>Check: if (x &lt; 10) { ... }</p>
<p>Keep together: 10&nbsp;km</p>
<span aria-label="smiling face">&#x1F60A;</span>
```

## Remember
- Entities begin with `&` and end with `;`.
- Use `&lt;`, `&gt;` and `&amp;` for reserved characters.
- Named, decimal and hex forms all display the same character.
