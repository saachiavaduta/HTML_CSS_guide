# Formatting Elements

Source: HTML/04.Formatting_Elements

## Key points
- Formatting elements style or mark up text inside a paragraph.
- `<b>` makes text bold only visually; `<strong>` makes it bold and marks it as important.
- `<i>` italicizes text; `<em>` adds semantic emphasis (stress), usually shown in italics.
- `<mark>` highlights text, usually with a yellow background.
- `<small>` shows fine print or side notes in a smaller font.
- `<del>` marks removed text (strikethrough); `<ins>` marks added text (underline).
- `<sub>` lowers text below the baseline (e.g. the n in A<sub>n</sub>); `<sup>` raises it (e.g. the nd in 2<sup>nd</sup>).
- `<blockquote>` quotes a long block of text (block-level); `cite` gives the source URL.
- `<q>` quotes a short inline text; browsers add quotation marks.
- `<abbr title="...">` marks an abbreviation; the title shows on hover.
- `<address>` gives contact information, usually in italics.
- `<cite>` names the title of a creative work (book, course, painting); it does not hold the quote itself.
- `<bdo dir="rtl">` overrides text direction, useful for right-to-left languages.

## Syntax / example
```html
<p>Learn at <b>Coding Gita</b> and <strong>practise daily</strong>.</p>
<p>Steve Jobs said, <q>Stay hungry. Stay foolish.</q></p>
<blockquote cite="https://example.com/workshops">
  A long quoted passage goes here.
</blockquote>
```

## Remember
- `<b>` and `<strong>` look alike, but `<strong>` carries meaning.
- Use `<blockquote>` for long quotes and `<q>` for short inline quotes.
- `<cite>` is for a work's title, not a person's name.
- `<abbr>` uses `title` to show the full form.
