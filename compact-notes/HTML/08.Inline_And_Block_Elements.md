# Block and Inline Elements

Source: HTML/08.Inline_And_Block_Elements

## Key points
- Every element is either block-level or inline, based on how the browser displays it.
- Block-level elements start on a new line and fill the full width of their parent.
- Block-level examples: `<div>`, `<p>`, `<h1>` to `<h6>`, `<ul>`, `<ol>`, `<form>`, `<section>`, `<article>`.
- Inline elements do not start a new line and take only as much width as their content.
- Inline examples: `<span>`, `<a>`, `<strong>`, `<em>`, `<img>`, `<b>`, `<i>`, `<q>`, `<abbr>`.
- Block elements can contain both block and inline elements; inline elements mainly hold text and other inline elements.
- `<div>` is a generic block container with no special meaning; it groups elements for styling or layout.
- `<span>` is the inline equivalent: a generic container for a small piece of text.
- CSS `display` can change this behaviour (e.g. `display: inline` or `display: block`).
- Prefer semantic tags such as `<section>` over a plain `<div>` when possible.

## Syntax / example
```html
<div class="card">
  <h3>Python Workshop</h3>
  <p>Visit <a href="https://codinggita.com">Coding Gita</a> for <strong>workshops</strong>.</p>
</div>
```

## Remember
- Block = new line, full width; inline = same line, content width.
- `<div>` is block-level; `<span>` is inline.
- `<a>`, `<strong>`, `<em>`, `<img>` are inline.
- `<p>`, `<h1>`, `<ul>`, `<section>` are block-level.
