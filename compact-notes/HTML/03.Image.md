# Image Tag

Source: HTML/03.Image

## Key points
- `<img>` embeds an image; it is a self-closing (void) tag.
- `src` gives the path or URL of the image file.
- `alt` gives alternative text for screen readers and shows if the image fails to load.
- `width` and `height` set the display size, in pixels unless CSS says otherwise.
- `loading` controls when the image is fetched: `lazy` (near the viewport), `eager` (immediately), `auto` (browser decides).
- Use `lazy` for images below the fold; use `eager` for critical images such as a hero image.
- If `loading` is not supported, the browser falls back to eager loading.
- `title` shows a tooltip on hover.
- `srcset` lists several versions of one image with their widths (e.g. `400w`); the browser picks the best one.
- `sizes` tells the browser how wide the image will be on the page, which helps the choice.

## Syntax / example
```html
<img src="flower.jpg" alt="A red rose in bloom" width="200" loading="lazy">

<img src="image-800.jpg"
     srcset="image-400.jpg 400w, image-800.jpg 800w, image-1200.jpg 1200w"
     sizes="50vw"
     alt="Example">
```

## Remember
- `src` and `alt` are the key attributes; `alt` helps accessibility.
- `<img>` has no closing tag.
- `loading="lazy"` delays off-screen images to save load time.
- `srcset` lets the browser choose the image size, not the developer.
